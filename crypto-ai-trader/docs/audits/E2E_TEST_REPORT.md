**問題：** `RiskManager(c)` 時 `drawdown_breaker` 和 `correlation_risk` 為 None，導致 `get_full_status()` 報錯。

# __init__ 中初始化

self.drawdown_breaker = DrawdownBreaker(binance_client) if binance_client else None
